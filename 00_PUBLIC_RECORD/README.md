README — Complete Decision Map

What this document is
The Complete Decision Map is the navigational spine of the forensic 
judgment analysis. It maps every decision across the Zahmoul 
proceedings — 16 decisions across 4 jurisdictions, from June 2023 to 
January 2026 — in a single chronological table with analytical tags.

It is the document to read first.

How to use it
Each row is one decision. Each row carries one or more analytical 
tags (FABRICATED, MISCHARACTERISED, SUPPRESSED, UNSUPPORTED, 
STANDSTILL). The tags are defined in Section A of the document.

When a tagged decision is of interest, the deeper analysis sits in 
one or more specific exhibits:

- Decision 4 (EWFC 79 — final judgment, 18 April 2024) 
  → see Ex29 (Logic Model) and Ex35 (Order Analysis MiPO format)

- Decision 6 (EWFC 114 — costs judgment, 24 May 2024) 
  → see Ex36 (Logic Model) and Ex20 (Order Analysis MiPO format)

- Decision 12 (8 May 2025 — set-aside dismissed) 
  → see Ex33 (Logic Model)

- Decision 8 (Moylan LJ — PTA refused, 23 December 2024) — not yet 
  built in Logic Model form

- Decision 13 (King LJ — reopen refused, 4 August 2025) — not yet 
  built in Logic Model form

- Decision 15 (Collins Rice J — JR permission refused, 11 March 2026) 
  — not yet built in Logic Model form

The wider analytical layer
The Complete Decision Map sits alongside two further analytical 
exhibits that read the pattern at a higher level of abstraction:

- Ex17 — Suppression of Disability — Preliminary. The mechanism by 
  which all findings were produced. To be read before any order 
  analysis.

- Ex38 — Institutional Betrayal and DARVO. The full 35-page 
  framework applying Smith & Freyd (2014) institutional betrayal 
  analysis and DARVO (Freyd 1997) to the documentary record across 
  all 16 decisions.

Read the Decision Map first for the shape of the sequence. Read 
Ex17 to understand the mechanism. Read Ex38 to understand the 
framework. Then read the per-decision exhibits where deeper analysis 
of any specific decision is needed.
