# OUTPUTS

Living analytical documents, chronologies, indices, and structured analysis.

These documents are updated regularly as proceedings develop. They represent the analytical backbone of the case — the intellectual framework connecting the evidence to the legal arguments.

## Subfolders

| Folder | Contents |
|--------|----------|
| `CHRONOLOGIES/` | All timelines, procedural chronologies, submission logs, weekly records |
| `ANALYSIS/` | Legal frameworks, grounds engagement tables, structured analytical work |
| `STATEMENTS/` | Position statements, institutional failure records, formal statements not filed with a court |
